# TÀN ẢO — Web Game Visual Novel Tương Tác

> **“Trải nghiệm một lựa chọn không ai muốn phải chọn.”**

Một dự án web game Visual Novel tương tác mang tính xã hội và giáo dục nhận thức, phản ánh thực trạng các nạn nhân bị lừa đảo việc làm lương cao và cưỡng ép lao động xuyên biên giới.

---

## 🌟 Tính Năng Nổi Bật

- **Cinematic Noir Visual Novel**: Phong cách đồ họa nghệ thuật 2D Graphic Novel đen tối, tối giản và kịch tính tâm lý (không sử dụng hình ảnh bạo lực hay máu me).
- **Hệ thống Âm thanh Thủ tục (Procedural Web Audio API)**: Tổng hợp âm thanh nhịp tim (heartbeat), tiếng cửa sắt (door thud), tiếng chuông tin nhắn, tiếng gõ phím và tiếng rền u uất mà không cần tải file âm thanh ngoài.
- **Mô phỏng Giao diện Messenger thật**: Màn chơi hồi hộp với thanh đếm ngược căng thẳng 20 giây và kịch bản ép buộc tương tác.
- **Sơ đồ cây quyết định & Tỉ lệ lựa chọn (Decision Flowchart)**: Theo dõi tiến trình cốt truyện, xem tỷ lệ cộng đồng và nhảy trực tiếp đến bất kỳ phân cảnh nào.
- **Hồ sơ bằng chứng & vật chứng (Evidence Drawer)**: Khám phá các tài liệu và thủ đoạn lừa đảo thực tế (giấy nợ khống, giấy tờ tùy thân bị giữ, định vị GPS giả mạo...).
- **4 Kết thúc độc lập (Endings)**:
  1. *Ending 1 — Người Thay Thế*
  2. *Ending 2 — Không Ai Thắng*
  3. *Ending 3 — Tín Hiệu Cầu Cứu*
  4. *Ending 4 — Người Bạn (Vòng Lặp Nhận Thức)*
- **5 Dấu hiệu nhận diện & Cứu nạn khẩn cấp**: Cung cấp kiến thức phòng ngừa thực tế và danh bạ đường dây nóng quốc gia (111, 113, Cục Lãnh sự).
- **Tràn viền & Tối ưu Responsive**: Hoạt động mượt mà trên cả máy tính lẫn thiết bị di động, hoàn toàn ẩn thanh cuộn gây vướng víu.

## 🛠️ Công Nghệ Sử Dụng

- **Next.js 14** (App Router)
- **React 18 & TypeScript**
- **Tailwind CSS**
- **Framer Motion**
- **Web Audio API**
- **Lucide React Icons**

---

## 🚀 Hướng Dẫn Cài Đặt & Chạy Cục Bộ

1. **Cài đặt thư viện**:
```bash
npm install
```

2. **Chạy máy chủ phát triển (Dev server)**:
```bash
npm run dev
```
Truy cập trình duyệt tại: `http://localhost:3000`

3. **Build bản phát hành (Production build)**:
```bash
npm run build
npm run start
```
